## 🐝 About the Project

A **Minecraft**-themed landing page featuring an animated 3D bee that follows the page scroll. This project was built during my early studies in **Web3D**, exploring in-browser 3D rendering with Three.js and scroll animations with GSAP.

> For the best experience, I recommend viewing the project on desktop.

---

## ✨ Features

- 🐝 **Interactive 3D model** — Minecraft bee loaded via GLTFLoader, with the model's own built-in animation
- 📜 **Scroll-driven animation** — the bee moves across the screen as the user scrolls, powered by GSAP ScrollTrigger
- 🎨 **Minecraft aesthetic** — custom fonts, background, and UI styled after the game
- 💡 **3D lighting** — ambient light + directional light to add depth to the model

---

## 🛠️ Technologies Used

| Technology | Use in the project |
|-----------|----------------|
| [Three.js](https://threejs.org/) | In-browser 3D rendering via WebGL |
| [GLTFLoader](https://threejs.org/docs/#examples/en/loaders/GLTFLoader) | Loading the bee's `.glb` model |
| [GSAP](https://gsap.com/) | Smooth animations |
| [ScrollTrigger](https://gsap.com/docs/v3/Plugins/ScrollTrigger/) | Syncing the 3D movement with scroll |
| HTML5 + CSS3 | Page structure and styling |

## 📚 What I learned

This project was my introduction to the world of **Web3D**. During development I explored:

- How to set up a **scene, camera, and renderer** with Three.js
- Importing and displaying **GLTF/GLB models** in the browser
- Controlling **3D model animations** with `AnimationMixer`
- Syncing 3D objects with **page scroll** via GSAP ScrollTrigger
- Setting up **3D lighting** to add realism to the model
